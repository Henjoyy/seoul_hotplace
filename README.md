# 서울의 다음 핫플레이스 — 스페셜티 커피

서울시 상권분석서비스 데이터(2021~2025, 행정동 425개)로 "뜨는 상권"의 초기 신호를 정의하고 검증해, 스페셜티 커피 업종의 추천 상권 3곳과 1순위 매장 컨셉을 제안한 조별 과제 결과물입니다.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 발표 자료 (브라우저로 열기, ←/→ 키로 넘김, F = 전체 화면). GitHub Pages로 바로 열림 |
| `뜬다_지표설계_초기신호.md` | 지표 설계, 데이터 확인 결과, 검증 과정 (커피 한정 결과는 미반영) |
| `시계열_권역_분기.csv` | 홍대·연남·합정망원·성수 권역의 분기별 점포·매출 시계열 |
| `초기신호_검증_행정동.csv` | 420개 행정동의 초기 신호와 전환 여부 (전 업종 기준) |
| `유튜브_동네별_수집.csv` | 동네별 유튜브 관련 영상 수 (검색 상위 샘플) |
| `구글트렌드_권역비교_2021_2026.csv` | 구글 트렌드 키워드 검색량 (분기 평균, 상대지수) |

## 핵심 결과와 한계
- 추천 3곳: 삼선동, 용산2가동, 가회동. 이는 가설이며, 초기 신호의 예측력은 통계적으로 입증되지 않았습니다 (순열검정 p=0.21).
- "스페셜티"는 업종 코드가 없어 독립(비프랜차이즈) 커피-음료 점포로 근사했습니다.
- 2021년 이후 자료만 사용했고, 네이버 검색량·인스타그램 해시태그·생활인구는 반영하지 못했습니다.
